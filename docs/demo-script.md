# MetaMining demo script (for video, ~7 minutes)

> Narrate over a live sim run (seed `why explanations persuade even when
> wrong`, 3 branches × 12 steps — the bm1 benchmark protocol, so footage
> matches the [tutorial](tutorial.md) numbers). Recording tip: run live
> for scenes 1–2 (~30 s of real run), then load
> `data/benchmarks/bm1-cartography.json` for scenes 3–5 (deterministic,
> re-take friendly).

1. **Hook (0:00–0:45).** "Language models are oceans; prompts are
   thimbles. MetaMining sends a crew of explorers into the water and
   maps what they find." Show the empty map, press Start.
2. **The dig (0:45–2:00).** Map fills with three branch colors; trails,
   gold strikes, telemetry vitals. Call out a warp and a weeds stop in
   the log — threads getting stuck and being retired.
3. **Radar (2:00–3:00).** Topology radar ticks b0/b1/b2 live. "Loops
   mean a branch is circling old ground; voids are chambers nobody
   entered." Show the Betti strip's amber activity.
4. **Shape tour (3:00–5:00).** Refresh each Shape view: merge-tree peak
   with Basin tint, barcode with Confidence bolding stable bars, loop
   rings + void on the map, density contours, Mapper nerve, timeline
   ribbons.
5. **Close the loop (5:00–6:00).** Suggest probe → `P?` marker → Probe
   it. Corroborate a peak from three lenses. Rotate the 3D terrain with
   Z: Coherence — spikes that become pits are confabulation suspects.
6. **Export + close (6:00–7:00).** Bundle JSON, Shape SVG, Methods
   paragraph. "Every run ends as citable data, not screenshots."
   Close on the honest limits: coherence isn't truth — the instrument
   finds suspects, the human assays the ore.

Shot list for B-roll: branch trails drawing, gold strike expanding
inline, time scrubber sweeping back, 3D auto-orbit, Mapper bins swept
4→12, the `P?` marker landing on the map.
